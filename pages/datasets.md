# Datasets
{: .no_toc }

Our main dataset is 140k Real and Fake Faces. CIFAKE was used first to check the method.
{: .lead }

## 140k Real and Fake Faces (main dataset)

| Property | Value |
| --- | --- |
| Source | [Hugging Face dataset](https://huggingface.co/datasets/RajuFace/140k-Real-and-Fake-Faces) (RajuFace), pinned revision `1f99c8e8` |
| Images | 140,000: 70,000 REAL + 70,000 FAKE |
| REAL images | Face photographs from the FFHQ dataset (Flickr-Faces-HQ) |
| FAKE images | Faces generated by StyleGAN, a generative adversarial network (GAN) [[9]](references.md) |
| Resolution | 256x256 pixels, stored as JPEG images |
| Original splits | Train 100,000; validation 20,000; test 20,000 |

**What we use.** Two separate files of the dataset:

| Role | File | Images used |
| --- | --- | --- |
| Training | `validation-00000-of-00002.parquet` | 5,000 REAL + 5,000 FAKE (all of the file) |
| Testing | `test-00000-of-00002.parquet` | 1,000 REAL + 1,000 FAKE (chosen by a fixed random seed) |

Training and test images come from different files, so no test image can appear in training.
Both classes have the same number of images, so 50% accuracy means guessing.

**Things to keep in mind.**

- All faces are aligned the same way (eyes and mouth in about the same place), which lets us
  compare the same face region across images.
- The dataset authors shrank the images to 256x256 and saved them as JPEG before we received
  them. Shrinking removes the finest details, which is where generator traces are often
  reported, so it may limit how well any frequency method can do here.
- Both classes were saved with the same JPEG compression settings, so a classifier cannot
  separate them by compression alone. We checked this directly (see
  [Classification](classification.md)).

## CIFAKE (method check)

| Property | Value |
| --- | --- |
| Source | [Kaggle dataset](https://www.kaggle.com/datasets/birdy654/cifake-real-and-ai-generated-synthetic-images) |
| Images | 120,000: 60,000 REAL + 60,000 FAKE |
| REAL images | CIFAR-10 photographs of everyday objects |
| FAKE images | Generated by Stable Diffusion 1.4, a diffusion model |
| Resolution | 32x32 pixels |

CIFAKE was mainly used to check that our feature extraction works. Its tiny 32x32 images limit
fine-detail analysis. **Our current focus is face images.**

{: .note }
The two datasets differ in content, resolution, and type of generator, so comparing them
does not isolate the effect of the generator.

## Why not GenImage?

Our original plan used a small subset of the GenImage benchmark [[1]](references.md). We
could not reassemble its split ZIP archive into a usable file, so we switched datasets. See
[Progress](progress.md) for how the dataset choice evolved.
